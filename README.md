# Привет, я Денис 👋

Frontend-разработчик с фокусом на Angular, 15 лет в коммерческой разработке.

## Обо мне

Начинал с JavaScript, HTML/CSS и PHP. В 2017 году перешёл на Angular (тогда ещё 4-я версия) и TypeScript — с тех пор это мой основной стек. Пишу бэкенд на Node.js с MikroORM, раньше — на Go. CI и деплой для своих проектов настраиваю сам.

Чем занимаюсь предметно: доработка и рефакторинг существующих Angular-приложений, поиск причин нестабильного поведения, производительность рендеринга, управление состоянием на NgRx и сигналах.

Коммерческие проекты ведутся в корпоративных GitLab, поэтому на GitHub видна только часть работы — собственные проекты и демо-кейсы.
